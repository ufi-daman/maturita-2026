# 📚 Témata 1-20

Tato složka bude postupně plněna podle 19denního plánu (`../PLAN_MATURITA_16_5.md`).

**Tempo:** 2 témata denně, dni 1-10. Den 11 = buffer.

## Formát každého `TEMA_XX.md`

```
# TÉMA X — Účto / Mng / Eko (název)

## 📘 1. Teorie (3 části)
### Účetnictví: ...
### Marketing/Management: ...
### Ekonomika: ...

## 🧮 2. Účetní příklad
Zadání + krok za krokem řešení.

## 📊 3. Ekonomický příklad
Výpočet (odpisy / mzda / DPH / BZ / HDP...).

## 🎤 4. Osnova 20min prezentace
Úvod (2 min) + 3 části (3×5 min) + závěr (3 min).

## ❓ 5. Q&A z seminářů
10 otázek z `EKO seminář - Téma X.pdf` + `MKTG MGM seminář - Téma X.pdf` se vzorovou odpovědí.

## ⚠️ 6. Slabá místa
Co učitel dle vašich zápisků testuje, kde studenti chybují.
```

## Generování pomocí Claude

1. Otevři `../prompts/01_shrnuti.md`
2. Připoj relevantní PDF z `../zdroje/`:
   - EKO seminář - Téma X.pdf
   - MKTG MGM seminář - Téma X.pdf
   - Účetnictví KP1B/KP2B kapitola pro téma X
3. Pošli Claudovi, ulož výstup sem jako `TEMA_X.md`
